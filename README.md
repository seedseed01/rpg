這是一款使用 C# 與 Spectre.Console 開發的 Console 文字 RPG 遊戲！<br>
玩家可以在鎮上閒晃、觸發奇遇事件、撿拾道具，並與各種魔物進行戰鬥。<br>
在不斷的探索與打怪之間慢慢前進，遊玩時間應該最多30分鐘。<br>
<br>
v1.0.0 版本更新內容<br>
戰鬥系統：實裝回合制戰鬥、屬性相剋機制。<br>
背包系統：支援道具使用、動態載入道具資料庫。<br>
隨機事件：新增多種鎮上隨機事件與趣味 NPC 對話。<br>
<br>
遊戲方式<br>
下載底下的 rpg.exe 檔案。<br>
雙擊 rpg.exe 即可直接開始遊玩（免安裝 .NET 環境）。<br>
